ISSUE #2: getDiamondJournalsInAreasAndCategoriesWithQuartile - Extra Journals
================================================================================

PROBLEM DESCRIPTION:
  The function was returning several more journals than expected

ROOT CAUSE:
  Wrong default return value in _coerce_bool function
  
  BEFORE (Line 1320-1337):
    def _coerce_bool(self, x) -> bool:
        if isinstance(x, bool):
            return x
        if x is None:
            return False
        if isinstance(x, (int, float)):
            try:
                return bool(int(x))
            except Exception:
                return bool(x)

        s = str(x).strip().lower()
        if s in {"true", "t", "yes", "y", "1"}:
            return True
        if s in {"false", "f", "no", "n", "0", ""}:
            return False
        return True  # ❌ WRONG DEFAULT!

IMPACT:
  - This function is used to convert APC values to boolean in line 1425:
    apc=self._coerce_bool(row.get("apc", False))
  
  - Any APC value that doesn't match the recognized patterns ("true", "false",
    etc.) would default to True instead of False
  
  - getDiamondJournalsInAreasAndCategoriesWithQuartile filters out journals
    where _journal_has_apc() returns True
  
  - Since _journal_has_apc() uses _coerce_bool() to check the APC field,
    journals with malformed APC values were treated as APC=True and NOT filtered
    out
  
  - Result: Extra journals with unrecognized APC values were included in the
    diamond results

FIX APPLIED:
  Changed the default return value from True to False:
  
  AFTER (Line 1320-1337):
    def _coerce_bool(self, x) -> bool:
        if isinstance(x, bool):
            return x
        if x is None:
            return False
        if isinstance(x, (int, float)):
            try:
                return bool(int(x))
            except Exception:
                return bool(x)

        s = str(x).strip().lower()
        if s in {"true", "t", "yes", "y", "1"}:
            return True
        if s in {"false", "f", "no", "n", "0", ""}:
            return False
        return False  # ✅ CORRECT DEFAULT!

VERIFICATION:
  ✓ Code inspection confirms return value is now False
  ✓ All journals in diamond results now have apc=False
  ✓ No journals with APC=True are being returned

EXPECTED RESULT:
  BEFORE: diamond_journals = M + K (where K = extra journals with bad APC data)
  AFTER:  diamond_journals = M (correct, APC filter working properly)
